# NerdHosting Backend

Este repositório contém o backend para uma hosting de Minecraft.

## Descrição

O projeto serve como API e lógica de servidor, também contendo Front End com HTMX para poder fazer uma hosting que consiga fazer inscrições de usuários, vinculação de contas com Google e Discord, pagamento e ativação automático de serviços pagos.

## Tecnologias

- HTMX + Tailwind CSS e DaisyUI
- Django 
- Banco de dados futuro (Postgress, sqlite por enquanto)

## Objetivo

Fornecer a infraestrutura necessária para gerenciar uma plataforma de hospedagem de servidores Minecraft na Nerd Hosting, uma nova hosting no Brasil!
